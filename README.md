# gpx-route-art

Mobile-first web app: draw a shape or word, snap it to real streets, export a GPX for a
watch (COROS Pace Pro). Built with TanStack Start (static SPA).

- Spec: [docs/BRIEF.md](docs/BRIEF.md)
- Deploy: [DEPLOYMENT.md](DEPLOYMENT.md)

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # vitest
pnpm build      # static site in dist/client
```
